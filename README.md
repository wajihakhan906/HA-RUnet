# HA-RUnet: Hybrid Attention Residual 3D U-Net

Hybrid attention residual 3D U-Net for volumetric brain tumor segmentation on BraTS-2020.

## Highlights
- Dice **0.867 / 0.813 / 0.787** (Whole Tumor / Tumor Core / Enhancing Tumor)
- Fewer parameters than ResUNet and AResUNet
- Hybrid channel (SE) + spatial attention inside residual blocks

## Tech Stack
PyTorch · 3D U-Net · Squeeze-and-Excitation · Attention gates
